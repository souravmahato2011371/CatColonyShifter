Privacy, plainly.

Prism Pop — Crystal Carnival is an early-access Android game. This page describes the privacy behaviour visible in the current app build and website.

Game data

The current Android manifest does not request internet access or other runtime permissions. The app is configured with Android backup disabled. Gameplay or settings data that the app stores locally remains on the device unless you remove the app or its data.

Website

This static website is hosted by GitHub Pages. When you visit it, GitHub may process standard server logs and technical information under its own privacy terms. The site does not include advertising trackers, analytics scripts or account sign-in.

External links

Links to GitHub take you to a third-party service governed by GitHub's own policies. Download APKs only from the official project releases and review the release details before installing.

Changes

This notice may change as the game gains features. If a future version adds online services, analytics or third-party SDKs, this notice should be updated before that version is distributed.
