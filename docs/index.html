04 / Good to know

Before you play.

Which devices are supported?

Prism Pop is built for Android 7.0 (API 24) and newer. Actual performance can vary by device.

Where does the download come from?

The download button points to the project's GitHub Releases. You can also browse release notes and previous builds there.

Is it free?

Yes. The game is offered as a free download. This early-access project is not affiliated with or endorsed by other match-three game publishers.

Where can I report a problem?

Visit the project's GitHub repository and open an issue with the device model, Android version and a description of what happened.
